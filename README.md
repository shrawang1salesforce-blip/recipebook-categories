# Recipe Book

A small recipe book that runs in the browser. Add a recipe, give it a category, and it will still be there the next time you open the page on this device.

Open `index.html` in a browser to get started. Recipes are saved in localStorage, so they stay in this browser and are not synced between devices.

You can search by name, filter by category, and add, edit, or remove recipes. The starter list is just there to make the page useful on first open; use **Clear sample recipes** to remove it.
